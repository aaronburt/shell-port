Passkeys

A passkey lets you sign in from the sign-in page without GitHub or an authenticator code. Your device checks it is really you (fingerprint, face or PIN) before it signs.

    You can only add a passkey while signed in. Your GitHub account must stay on this server's allowlist.

    SSH key passphrases
    Passphrase auto enterRemember the passphrase for each host after you type it once, and enter it for you next time. Stored only in this browser, encrypted with a key the browser cannot export. Never saved on the server.
    Riskier option. The passphrase is left in this browser's storage. Anyone who can use this browser profile while you are signed in, or run code in this page, can read it and unlock your SSH key. Only turn this on for a device you fully trust.
